GEORUSH SEO - DESKTOP BACKUP APP

For administrator:
1. Copy this folder to the Windows marketing laptop.
2. Run INSTALL-GEORUSH.bat once.
3. After setup, run GEORUSH-SEO-START.bat.

For marketing users:
Double-click GEORUSH-SEO-START.bat.
GEORUSH opens in the browser and the crawler/API runs locally.

The laptop must have internet access for crawling external websites.

This package is a desktop backup. It does not replace the cloud deployment.
