GEORUSH SEO v16 — LIVE DESKTOP APP

IMPORTANT:
This desktop app opens the LIVE GEORUSH website inside a native Windows application window.
It does NOT start a local Python server and does NOT use 127.0.0.1.

Live site:
https://pharmaqa-ops.github.io/GEORUSH-SEO/

Windows installer:
The included GitHub Actions workflow builds a single GEORUSH-SEO.exe and an Inno Setup
installer with a normal Windows uninstall entry.

BUILD:
1. Upload these files to the GEORUSH-SEO GitHub repository.
2. In GitHub, open Actions -> Build GEORUSH Windows Desktop.
3. Click Run workflow.
4. Download the GEORUSH-SEO-Windows-Installer artifact.
5. Run GEORUSH-SEO-Setup.exe on the marketing laptop.

MARKETING USER:
After installation, double-click the GEORUSH SEO desktop icon.
The live GEORUSH site opens inside the app.

UNINSTALL:
Windows Settings -> Apps -> Installed apps -> GEORUSH SEO -> Uninstall.
