# GEORUSH Logo Asset Guide

Source artwork supplied by the GEORUSH owner was used without changing the underlying mark.

## Asset types

- `GEORUSH-symbol-primary-blue.png` — primary symbol
- `GEORUSH-symbol-black.png` — monochrome black
- `GEORUSH-symbol-white.png` — reverse/white
- `GEORUSH-symbol-blue.png` — flat brand blue
- `GEORUSH-symbol-grayscale.png` — grayscale
- `GEORUSH-wordmark-black.png` — black GEORUSH SEO wordmark
- `GEORUSH-wordmark-blue.png` — blue wordmark
- `GEORUSH-wordmark-white.png` — reverse wordmark
- `GEORUSH-lockup-*.png` — symbol + wordmark lockups
- `GEORUSH-icon-*.png` — app/web icon sizes
- `GEORUSH.ico` — Windows icon
- `GEORUSH-social-dark-1200x630.jpg` — social preview
- `GEORUSH-social-light-1200x630.jpg` — light social preview
- `GEORUSH-header-lockup.png` — report/header use
- `GEORUSH-logo-sheet.png` — visual reference sheet

## Usage

Blue: primary UI and brand use.

Black: white/light documents, print, monochrome use.

White: dark backgrounds and the loading screen when needed.

Icon: favicon, Windows shortcut, application icon.

Wordmark: reports, presentations, email/signature and wide headers.

Do not stretch, skew, rotate or recolor the source mark beyond the supplied variants.
